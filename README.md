# 🎭 Acerca del proyecto

**EventPro** es una plataforma full-stack enfocada en la administración de eventos, recursos y servicios para empresas organizadoras, salones, negocios de catering y compañías de entretenimiento.

El sistema fue diseñado para:

- 📅 Gestionar eventos y reservaciones
- 🏛️ Administrar venues y espacios
- 🎁 Configurar paquetes de eventos
- 📸 Gestionar servicios y proveedores
- 👥 Controlar usuarios y administradores
- 📊 Monitorear recursos y bookings
- ⚡ Automatizar procesos organizacionales

La plataforma ofrece una experiencia completa de planificación de eventos mediante una arquitectura modular y escalable.

# 🚀 Configuración del proyecto

## 1️⃣ Clonar repositorio

```bash
git clone https://github.com/isairey/PlataformaGestionEventosServicios.git
```

---

## 2️⃣ Entrar al proyecto

```bash
cd PlataformaGestionEventosServicios
```

---

## 3️⃣ Instalar dependencias

```bash
npm install
```

---

## 4️⃣ Configurar base de datos

```env
DB_HOST=
DB_USER=
DB_PASSWORD=
DB_NAME=
```

---

## 5️⃣ Ejecutar migraciones

```bash
npm run migrate
```

---

## 6️⃣ Ejecutar servidor

```bash
npm run dev
```

---

## 7️⃣ Abrir aplicación

```bash
http://localhost:3000
```
